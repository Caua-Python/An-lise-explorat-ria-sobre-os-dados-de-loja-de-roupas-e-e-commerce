# An-lise-explorat-ria-sobre-os-dados-de-loja-de-roupas-e-e-commerce
Desenvolvi uma análise exploratória sobre os dados de uma loja de roupas e e-commerce para colocar meus estudos em prática! 🚀



Primeiro, eu dei um display para dar uma visualizada na tabela, e então, verifiquei se tinham valores nulos ou duplicados, como haviam nulos, eu pensei: "eu poderia preencher esses nulos, porém as colunas que eles se encontram estão todas vazias".



Portanto, decidi remover os nulos. Logo depois, verifiquei os valores estatísticos dos produtos registrados, os únicos, o que mais se repetia e a frequência. Também decidi dar um value.counts() na coluna Size para ver quantos produtos haviam sido registrados em cada tamanho e, por fim, chequei os produtos com estoque zerado



Uma coisa que eu reparei é que alguns valores da coluna SKU Code estavam como "#REF!", logo eu entendi que eram falsos nulos, portanto eu substitui esse texto por "Not Found".



Foi um projeto bem simples e legal, mas foi bom para praticar algumas funções que eu aprendi e melhorar minha interpretação sobre os dados!
